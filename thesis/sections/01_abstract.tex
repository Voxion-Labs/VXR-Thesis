\begin{abstract}
WebAssembly (Wasm) has emerged as the premier sandboxed execution environment for multi-tenant edge compute nodes due to near-native execution speeds and sub-millisecond cold starts. However, when operating under extreme memory constraints (e.g., 512MB RAM micro-containers), traditional host-guest Foreign Function Interfaces (FFI) suffer from severe boundary serialization taxes: double-buffering ($\text{memcpy}$) and general-purpose guest dynamic allocator fragmentation ($\mathcal{O}(N)$ free-list traversal). In this paper, we propose and evaluate \textbf{VXR-Thesis}, a systems architecture uniting direct linear memory zero-copy ring buffers with deterministic $\mathcal{O}(1)$ slab and monotonic arena allocators. We construct an empirical testing framework comprising a C++ kernel compiled to standalone Wasm, orchestrated by a zero-CGO Go runtime, with telemetry logging microsecond latency profiles across varied payload dimensions (64B to 64KB) and concurrency levels (1 to 32 worker threads). Our empirical results prove that zero-copy linear memory slicing eliminates intermediate host heap allocations ($0\text{ B/op}$) and bounds $p99$ tail latency divergence under severe thread contention, maintaining flat memory RSS profiles with zero garbage collection spikes within the 512MB RAM ceiling. Both execution pipelines yield identical 64-bit cryptographic checksums, validating algorithmic correctness while proving zero-copy boundary elimination as an essential primitive for low-latency edge virtualization.
\end{abstract}
